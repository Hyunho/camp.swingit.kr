# 프로젝트 문서

이 디렉토리는 캠프 스윙잇 프로젝트의 상세 문서를 포함합니다.

## 문서 목록

- [`TECH_STACK.md`](./TECH_STACK.md): 프로젝트에 사용된 기술 스택 및 라이브러리 버전.
- [`PROJECT_STRUCTURE.md`](./PROJECT_STRUCTURE.md): 디렉토리 구조 및 파일 명명 규칙.
- [`CONVENTIONS.md`](./CONVENTIONS.md): 코딩 스타일, TypeScript 설정, 컴포넌트 패턴 등의 규칙.

## AI 에이전트 참고

AI 에이전트는 루트 디렉토리의 `.cursorrules`를 참조하거나, 이 문서들을 통해 프로젝트의 컨텍스트를 파악할 수 있습니다.
