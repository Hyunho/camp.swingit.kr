# 기술 스택

## 코어 (Core)
- **Next.js**: 14.x (App Router 사용)
- **React**: 18.x
- **TypeScript**: 5.x

## 스타일링 (Styling)
- **Tailwind CSS**: 3.x
- **Headless UI**: 접근성 높은 UI 컴포넌트 라이브러리
- **Tailwind CSS Animate**: 애니메이션 유틸리티
- **Typography Plugin**: 본문 텍스트 스타일링 플러그인

## 콘텐츠 (Content)
- **MDX**: `@next/mdx`, `remark-gfm`, `@mapbox/rehype-prism`

## 유틸리티 (Utilities)
- **clsx**: 클래스 이름 병합 유틸리티
- **feed**: RSS 피드 생성
- **fast-glob**: 파일 시스템 탐색

## 개발 도구 (Dev Tools)
- **ESLint**: Next.js 설정 포함
- **Prettier**: Tailwind 플러그인 포함
